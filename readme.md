# Textile Color Combination & LAB Color App

This is a simple web application made with Python and Streamlit.

## Features

- Shows primary RGB colors:
  - Red
  - Green
  - Blue
- Creates simple color combinations.
- Allows users to enter LAB values.
- Generates a color from LAB values.
- Shows LAB, RGB and HEX values.
- Simple interface for textile students.

## Files

Main Python code of the application.

Contains the required Python library.
